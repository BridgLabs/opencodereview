## 10. How to sign

1. On your first pull request, a bot asks you to sign. Add a comment to the pull request with this line:

   ```text
   I have read the OpenCodeReview Contributor Assignment Agreement 1.1 and I agree to it.
   ```

2. Each author of a commit in the pull request signs with the same comment, from their own GitHub account.
3. The comment from your GitHub account is your electronic signature. It applies to all Contributions that you sent and will send with that account.
4. The Maintainer keeps a record of each signature on the `cla-signatures` branch: your GitHub login, your GitHub user ID, the pull request and the time.
5. A new version of this agreement applies only after you sign it. This version continues to apply to the Contributions that you sent before.
